# 竞品情报系统 · 使用说明书

> 面向业务同事的操作手册。不需要任何技术背景。
>
> 你只需要做两件事：**每天看微信推送**、**需要时打开看板查**。

---

## 一、这套系统帮你做什么

它替你**每天自动盯着 40 多家竞争对手**，把值得注意的动静挑出来告诉你。

**盯着什么**：

| 盯的内容 | 举例 |
|---|---|
| 对手股权/战略变动 | 今天国际控制权拟变更、国自机器人被杭叉集团并购 |
| 对手拿钱 | 某竞品完成数亿元融资、港股递表 |
| 市场机会 | 医院/学院/工厂发布仓储机器人采购招标 |
| 谁中了标、多少钱 | 苏州某公司以 49.2 万中标某院疫苗仓储项目 |
| 对手出新品 | 发布新型控制器、亮相工博会 |
| 对手官网变动 | 悄悄改了产品页或招聘页 |
| 行业政策 | 工信部发布制造业数字化转型相关文件 |

**你不用做任何操作** —— 系统每天早上 9 点自动跑一遍。

---

## 二、怎么打开看板

### 方式一：公司内网访问（推荐，同事都是这个）

在浏览器里输入：

```
http://192.168.2.28:8000
```

> 这个地址**在公司网络内**任何设备都能打开（电脑、手机都行）。
> 不需要装任何东西。

### 方式二：本机访问

如果就在这台电脑上，也可以用：

```
http://127.0.0.1:8000
```

### 打不开怎么办

| 现象 | 处理 |
|---|---|
| 提示"无法连接" | 服务可能没启动，找技术同事重启 |
| 同事能打开、你打不开 | 检查是否连了公司网络（别用手机热点） |
| 一直转圈 | 换个浏览器试试 |

## 三、看板界面怎么用

### 顶部两个标签页（最重要）

```
┌─────────────┬─────────────┐
│  每日情报    │  深度分析    │
└─────────────┴─────────────┘
```

| 标签页 | 里面是什么 | 什么时候看 |
|---|---|---|
| **每日情报** | 每天采集的动态：媒体报道、招标、公告、政策 | **日常盯动态看这个** |
| **深度分析** | 针对每个对手的完整战略分析报告 | 要研究某个对手时看 |

**切换标签页时，下面的筛选条件会自动重置** —— 这是正常的，因为两个页面的数据性质完全不同。

---

### 上方四张数字卡片

```
┌────────┬────────┬────────┬────────┐
│  全部   │ 今日新增 │  未读   │ 已加星  │
│  467   │   15   │  467   │   0    │
└────────┴────────┴────────┴────────┘
```

**这只是数字，点不了。** 用来快速了解"现在有多少条、今天新增多少"。

---

### 筛选栏（找到你要的信息）

| 控件 | 作用 | 例子 |
|---|---|---|
| **搜索框** | 按关键词找 | 输入「海柔」只看海柔相关 |
| **全部竞品** | 只看某个对手 | 选「快仓智能」 |
| **信号类型** | **多选**，按类型筛 | 勾选「重大变更」+「订单信号」 |
| **时间** | 限定时间段 | 选「近 7 天」 |
| **全部状态** | 未读 / 已读 / 归档 | 选「未读」快速清理 |
| **排序** | 换排序方式 | 「最新优先」「相关度优先」 |
| **显示低相关度** | 默认不勾 | 勾上能看到更多，但杂音多 |

**信号类型是多选**：点开下拉，勾选你想看的类型，可以同时选多个（结果取"或"的关系）。

**信号类型有哪些**：

| 类型 | 含义 |
|---|---|
| 重大变更 | 控制权变动、并购、重组 —— **最需要关注的** |
| 融资动态 | 对手拿到投资 |
| 订单信号 | 对手中标或拿到大单 |
| 新品发布 | 对手推出新产品 |
| 竞品命中 | 媒体直接提到竞品 |
| 官网变更 | 对手官网内容变了 |
| 中标 / 招标 | 具体的招投标信息 |

---

### 每条信息怎么看

每条记录**左边是概要，右边是详细内容**：

```
┌──────────────────────────────┬─────────────────────────┐
│ 【新品发布】某公司发布新型控制器 │  提炼                    │
│  ↳ 对手推出新品，需对比差距     │  这家公司是谁、做什么、  │
│                              │  对我方什么威胁、         │
│  原始标题（小字）              │  我们该做什么             │
│  来源 · 时间 · 相关度          │                          │
│                              │                          │
│  [打开原文] [添加备注] [加星]  │                          │
└──────────────────────────────┴─────────────────────────┘
```

**只看左边第一行大字就够了** —— 那是系统替你总结好的"发生了什么"。
想深看再点**「打开原文」**。

---

### 右侧「提炼」栏是什么

**这是系统最有价值的部分** —— 它不只是转载标题，而是**告诉你这条信息意味着什么**。

深度分析里的「提炼」会这样写：

> **定位**：这家公司以"料箱机器人+控制器"为核心，融资超 5200 万美元
> **威胁**：主打出海东南亚，但缺无人叉车和料箱机器人
> **行动**：本季度完成其产品功能拆解，强化我方全栈能力对比

**最后那个"行动"是重点**，直接告诉你该干什么。

---

### 每条能做什么

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **查看完整报告** | 打开深度报告全文（仅深度分析里有） | 研究对手 |
| **打开原文** | 跳到来源网页 | 想深看 |
| **添加备注** | 写下你的判断 | 如"这个项目我们跟过" |
| **标为已读** | 处理过了 | 清理未读 |
| **加星** | 重要，回头再看 | 标记重点 |
| **归档** | 从列表移走 | 不相关的 |

**多条一起处理**：左边勾选多条 → 底部会出现批量按钮。

---

### 筛出来是空的怎么办

如果筛选后没有结果，界面会告诉你原因：

```
当前条件下没有记录
生效的条件：竞品＝海康机器人 · 时间＝近 1 天 · 仅高相关度
[清除全部筛选]
```

**点「清除全部筛选」** 一键回到初始状态。

> 注意：**筛选条件不会自动取消**。比如你选了"海康机器人"又改成"近 1 天"，
> 如果它这几天没动静，就会显示 0 条 —— 这是**如实告知**，不是坏了。

## 四、推荐的使用节奏

### 每天早上（1 分钟）

1. 看企业微信推送 —— **只扫标题**
2. 没有推送 = 今天没大事，不用管

### 每周一次（10 分钟）

1. 打开看板 → 点「信号类型」→ 勾选 **「重大变更」**
2. 看看有没有漏掉的战略级信号
3. 再勾选「订单信号」，看市场机会和对手中标情况
4. 对值得跟进的记录**加星或写备注**

### 需要研究某个对手时

1. 切到 **「深度分析」** 标签
2. 在「全部竞品」里选那个对手
3. 点 **「查看完整报告」**

**报告里有**：定位、威胁分析、SWOT、以及**建议我们本季度做什么**。

## 五、常见问题

### Q：今天没收到推送，是坏了吗？

**大概率没坏。** 系统只在**有新信号时**才推送。

**想确认**：打开看板，看「今日新增」卡片是不是 0。

### Q：看板打不开

1. 确认连着**公司网络**（别用手机热点）
2. 让技术同事确认服务在运行
3. 换个浏览器试试

### Q：「显示低相关度」要不要勾？

**默认不勾就行**。不勾时系统只显示相关度较高的内容，已经过滤掉大部分噪音。

**什么时候勾**：觉得"信息太少了"时，勾上能看到更多，但杂音也多。

### Q：「相关度」是什么意思？

系统给每条信息打的**价值分**（0~1）。

- **0.9 以上**：直接相关的硬信号（竞品中标、重大变更）
- **0.7~0.9**：相关行业动态
- **低于 0.7**：默认不显示

### Q：为什么有些竞品没什么信息？

**不是所有对手都想被报道**：

- **未上市公司**（如海柔创新、快仓）：没有公告披露义务
- **做大型商业项目**：不进政府采购，公开渠道看不到
- **媒体曝光少**：垂直媒体报道有限

**系统已尽量覆盖**：40 多家对手每个都至少有数据可查。

### Q：数据是全自动的吗？

**是。** 每天早上 9 点自动：采集 → 分析提炼 → 生成日报 → 推送企业微信。

**你什么都不用做。**

### Q：为什么我选了竞品又改时间，结果变成 0 条？

**因为那个对手在这段时间内确实没有记录。** 系统会如实显示，并告诉你哪些条件在生效。

**不是坏了** —— 点「清除全部筛选」就能回到初始状态。

### Q：备注会同步给别人吗？

**不会。** 备注存在本机数据库里，但**所有人看到的是同一份数据** ——
也就是说，别人打开看板能看到你写的备注。

**敏感判断建议写在别处。**

### Q：能加新的竞争对手吗？

**可以，但需要技术同事改配置**。告诉我你想加谁。

## 六、一句话总结

> **每天早上看企业微信 → 有值得关注的再打开看板 → 重要的加星或写备注。**

系统替你盯着 40 多家对手，你只需要花几分钟处理它挑出来的重点。

## 附三、数据说明（给想了解细节的人）

**信息来源**：全部来自公开渠道

- 上市公司公告（交易所公开数据）
- 政府采购网招标/中标公告
- 行业垂直媒体
- 竞品官网
- 政府政策发布

**每条记录都带原文链接**，可点「打开原文」核对。

**系统不会编造事实** —— 所有内容都是从公开渠道抓的原话。
只有"影响判断"那部分是根据信息类型给的归纳，会标注依据。
深度报告里如果某个维度没查到数据，会明确写"数据不公开"，不会瞎猜。

**更新频率**：每天早上 9 点自动更新一次。
